# Cozy Lite first-test checklist

This is a **candidate**, not a validated playable release.

- [ ] Back up / duplicate Steph's existing modpack profile
- [ ] Note Oculus version and Z1 / Z1 Extreme if discoverable
- [ ] Launch at 720p, 6–8 render chunks; note device power profile
- [ ] Shader appears in Oculus shader menu
- [ ] Shader loads without compile/link errors
- [ ] Ordinary blocks and modded terrain render normally
- [ ] Water, lava, glass and other translucent blocks render
- [ ] Caves and underwater scenes remain readable
- [ ] Rain, snow, puddles, moon and aurora appear as intended
- [ ] Compare FPS, stutter and memory usage with shader off/on
- [ ] Revisit typical demanding locations in Steph's actual modpack

If something fails, note the exact scene and save the relevant logs.
The goal is **beautiful and playable on Steph's ROG Ally**, not a benchmark
score or an artificial feature count.
